            Zugang zu GitHub

            Die App liest und schreibt direkt im Repo MagellBinell/3DMOLL. Dafür braucht sie einmal einen Schlüssel von GitHub. Er bleibt nur auf diesem Gerät gespeichert und geht nur an GitHub.

            1. Auf github.com: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
            2. Repository access: Only select repositories → 3DMOLL.
            3. Permissions: Contents Read and write, Issues Read and write. Ablauf: 1 Jahr.
            4. Schlüssel kopieren und hier einfügen.
